# Maritime Daily Digest

해운 일일 동향 뉴스 포털 — 12개 카테고리 × 10건(총 120건), 한국어/영어 토글, 날짜 아카이브.

- `index.html` — 메인 페이지(자체 완결형). 더블클릭하거나 GitHub Pages URL로 접속.
- `data/digest-YYYY-MM-DD.js` — 날짜별 데이터(매일 추가)
- `data/manifest.js` / `manifest.json` — 날짜 목록(최신순)

데이터는 매일 자동 생성되는 디지에스트로 갱신됩니다. 출처 링크는 원문 기사로 연결됩니다.

## GitHub Pages
저장소 Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `/ (root)` 선택 후 저장하면
`https://<사용자명>.github.io/<저장소명>/` 에서 누구나 접근할 수 있습니다.
